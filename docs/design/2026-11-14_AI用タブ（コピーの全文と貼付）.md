# AI用タブ：コピーした全文の受け取りと、貼付の代わり（2026-11-14）

**2026-11-14 実装済み。**

## すみぽんの指示（2026-11-14）

- 操作する AI エージェントのブラウザはクリップボードを読めないので、コピーボタンを押しても文面を受け取れない。
- コピーしたプロンプトの全文を、クリップボード以外でも受け取れるようにする（画面の読み取り専用の欄、または TXT）。
- 日本株版は文面を別にもらって運用できたが、米国株版は開発中で文面が変わるので、この経路が要る。
- 対象は全自動版のすべてのコピーボタン（分析プロンプト、手動フロー①〜④のプロンプトなど）。
- 自分も使うので、いまの画面にテキストボックスを増やさない。同じボタンやボックスを AI 用の作業タブに写すのはよい。

## 作ったもの

上のタブに「AI用」を足した（週間まとめの右）。全自動版の画面には何も足していない。

- **コピーした全文**：全自動版（または AI用タブ）でコピーボタンを押すと、クリップボードへのコピーと同時に全文を控え、読み取り専用の欄に出す。履歴は最新10件（ボタンの名前・時刻・字数）。「⬇ TXT」で保存（ファイル名は `ssg-prompt_年月日-時分秒.txt`。日本語のファイル名は、AI が操作するブラウザ（Playwright の Chromium）が無視して「download」にしたので英数字だけにした）。
- **貼付用**：この欄に文が入っていれば、📥 貼付・📋 貼付のボタンはクリップボードの代わりにこの文を使い、欄を空にする。空のときはいつもどおりクリップボードを読む（人が使うときは変わらない）。手動フローで ChatGPT の回答を戻すのに要る。
- **コピー・貼付ボタン**（2026-11-14 すみぽん「タブ名の見出しの下に並べる。同じボタンは同じ名前」）：画面名（東証 全自動版／米国版）の見出し → 工程（①②③④⚙）の見出し → 元の画面の行ごと（行の見出し＝行の中の見出しか、折りたたみの見出し）に、**元のボタンと同じ名前・同じ順**で並べる。手動フローの「📋 ①台本 📥 貼付 → …」の矢印も写し、コピーと貼付の組は改行で離さない。押すと元のボタンを `click()` するので、処理・結果・状態の表示・作業の保存はすべて元の画面と同じ（AI用タブにしか無いのは、コピーした全文の控えと貼付用の欄だけ）。一覧は AI用タブを開いたときに、いまの置き場所から集める（東証の全自動版では ④・⑤ の部品が ③動画・④SNS に移っているため）。区別用の名前（`data-btn`。例：📥 貼付（①台本））は、ボタンの上にマウスを置いたときの説明と、コピーの履歴・操作の記録・アカウント管理に使う。

## しくみ

- `index.html` の先頭の小さなスクリプトで、`navigator.clipboard.writeText`・`document.execCommand('copy')`（クリップボード API が使えないときの代わり）・`navigator.clipboard.readText` を横取りしている。各コピーボタンの関数には手を入れていない。今後コピーボタンを足しても、この2つを使えば自動で控えに入る。
- 控えは `window.ssgCopies` と `sessionStorage` の `ssg_ai_copies`（タブを閉じると消える）。
- ボタンの名前は `data-btn`、無ければ表示の文字。「📋」だけのボタンは同じ行の見出しを付ける。見分けにくいボタンには `data-btn` を付けた（📋 分析RANK・📋 名称RANK・📋 銘柄名一覧表・📋 貼付（ファクトチェックのレポート）・📥 貼付（①台本）〜（④スライド文章））。
- 対象：全自動版の工程（① ② ③動画 ④SNS ⚙設定）にある、`onclick` に Copy・Clip・Paste・apCopy を含むボタン。全自動版で出ないもの（`.auto-only`）と、全自動版に無い工程（③音声生成・④スライド・⑤出力）は除く。

## 米国版

- 米国版（`us.js`）のコピーも `autoClip` を使うので、全文は自動で控えに入る。📋 貼付（`usPasteReport`）も貼付用の欄を使える。
- AI用タブの一覧に「米国版 ①〜④・⚙」の工程として並べる（`#tabUs` の `.us-step[data-step]`）。
- 米国版のコピー・貼付ボタンに名前（`data-btn`）を付けた：米国版 📋 AI収集プロンプト・米国版 📋 貼付（AIのレポート）・米国版 ✅ CK・米国版 📋 台本・米国版 📋 動画のデータ（JSON）・米国版 📋 サムネ案・米国版 📋 X投稿文。
- 確かめたこと（ローカル）：米国版を開いてから AI用タブを開くと米国版の画面は隠れ、米国版のボタンが工程ごとに並ぶ。貼付用の欄から「米国版 📋 貼付（AIのレポート）」に入る。
- 米国版に新しいコピーボタンを足すときは、`autoClip`（または `navigator.clipboard.writeText`）を使い、`onclick` の関数名に Copy・Clip・Paste のどれかを入れると、AI用タブに自動で並ぶ。名前は `data-btn="米国版 📋 〜"` を付ける。
