# 全自動版の画面構成を作り直す（方針・2026-10-10）

全自動版は動画（⑥）が成果物になり、スライド画像は使わない。今は自動版と同じ画面に⑥を足しただけなので、作業の順序に合わせて画面を組み直す。**2026-10-11 実装済み**（下の「決めた構成」）。

## すみぽんの指示（2026-10-10）

- スライドはいらない（スライド画像のプレビュー・ZIP は不要）。
- 台本を作るのも、台本を分けるのも、**動画タブ**でよい。
- **サムネ**と**音声生成**も動画タブに移す。
- 「出力」ではなく **SNS タブ**にする（X 投稿文・縦型サムネなど）。
- 縦型サムネはこのあと作るので必要。台本の MP3 も一応必要。
- 画面の並びは**実施する順序**に合わせる。

## いまの全自動版（自動版と同じ画面＋⑥）

①取得・抽出 → ②ファクトCK → ③音声生成 → ④スライド → ⑤出力 → ⑥動画 → ⚙設定

## 組み直すときに決めること（次回、たたき台を出して相談）

- 動画タブの中の順序（台本 → 読み上げ → データ・一言とまとめ → 画像・サムネ → プレビュー → MP4）。
- スライド文章（④）は動画のデータの元なので、画面に出すか裏で作るだけにするか。
- SNS タブに入れるもの（X 投稿文、縦型サムネ、台本の MP3 など）。
- 自動版・手動版は「念のため残す」ので触らない。

## 決めた構成（2026-10-11 すみぽん）

- ①取得・抽出 → ②ファクトCK はそのまま。
- 音声生成はいらない（動画タブで読み上げを作る）。スライド・出力は外す。
- ③動画：ChatGPT用プロンプト（ニュース画像・まとめ画像）、サムネ案、サムネ文言、ニュース画像 → その下に動画（台本は2行、左6：右4でプレビューは右）。
- ④SNS：MP4・サムネの出力ボタン、投稿文（縦型サムネもここ）。
- 2026-10-11 変更：縦の動画を追加。サムネ（横・縦とも）は③動画で直す（縦型サムネの文言もここ）。サムネは動画の冒頭に入るので、画像としては保存しない。④SNS は「🎬 横動画」「🎬 縦動画」の書き出しと X 投稿文だけ。
- 実装は、自動版の④スライド・⑤出力にある部品をそのまま動かす（`autoPlaceBlocks`）。自動版に戻すと元の場所へ戻る。
- 2026-10-13 追加：②ファクトCK の「ファクトチェック完了」の下に「ChatGPTで手動（APIが遅いとき）」を置いた。API と同じ4つの生成（①台本→②全情報→③サムネ/X→④スライド文章）を、📋 でプロンプトをコピー→ChatGPT に貼る→回答をコピー→📥 貼付、の順で戻す。貼付すると次のプロンプトを自動でコピーし、回答のコードブロックは外す。最後の「ChatGPT完了（次へ）」で、全自動版は動画のデータ作成と冒頭/まとめの AI（これは Gemini のまま・短い）を動かして動画タブへ進む。
- 2026-10-13 追加：BGM。⚙設定に「BGM（動画）」の欄（kessan-tool の 設定 › BGM と同じ：何本でも登録・使う曲を1つ選ぶ・IndexedDB の ssg-bgm に保存）。③動画の部品（kessan-viz.js）に `importBgm` で渡し、部品が BGM の行（入れる・音量 3%・ツールの BGM を使う・ファイルを選ぶ・外す）を出して、動画の全体にループで流す。曲がまだ無ければ最初に自動で取り込む。
- 2026-10-15 修正：縦動画（横動画も）の書き出しで、サムネ・表紙のあとの場面（チャートなど）が真っ白になることがあった。原因は、MP4 の書き出し用の隠しプレイヤーが ④SNS のカードの中（書き出しボタンの横）に作られること。書き出し中に ③動画 など別の工程を開くと ④SNS のカードが `display:none` になり、隠しプレイヤーの大きさが 0 になって、それ以降のコマが背景だけになる（部品単体のページでは起きず、index.html の工程切替で再現）。部品 kessan-viz.js の書き出しボタン（SF）で、隠しプレイヤーを `createPortal` で `document.body` 直下に置くようにして直した（工程を切り替えても影響を受けない）。**kessan-visualizer 側の元ソースにも同じ変更を入れること**（次の `npm run to-tse` で上書きされるため）。
