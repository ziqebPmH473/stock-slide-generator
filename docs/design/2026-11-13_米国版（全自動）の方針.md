# 米国市場の振り返り（全自動版）の方針（2026-11-13）

日本（東証）の全自動版に加えて、米国市場の振り返り動画を作る。**まだ相談の段階で、実装はしていない。** データの取得先は確認済み（下の「取得先の確認結果」）。

## すみぽんの指示（2026-11-13）

- 全自動版で作る。作りは東証の全自動版と同じ。
- 個別株ランキング・業種別の場面は**なし**。
- 指数は米国のほかに、日経先物・ドル円・ビットコイン・金・債券金利も出す（場面は分けてよい）。SOX・ラッセル2000・VIX・原油も入れる。
- ニュースは市場全体のほかに、**個別株のページ**も作る。
- **決算一覧表**を作る（当日に決算を発表して大きく動いた株、注目度の高い株。値動き・コンセンサス・実績）。引け後の発表は時間外の値動きが大事なので、時間外も入れる。
- ニュースと個別株の情報は **AI で収集**する。
- ただし、**指数・変動率の高い銘柄（候補）・決算銘柄の一覧はツールが取得して、プロンプトで AI に渡す**（数字を AI に調べさせない）。
- 決算の予想・実績は、使えるなら Finnhub を使う。
- 成果物は横動画・縦動画・X 投稿文。週間まとめはまだ決めないが、あとからできるようにしておく。

## 前提：時間の扱いが東証版と違う

- 米国市場が閉まるのは日本時間の朝 6:00（冬時間。夏時間は 5:00）。作るのは日本の朝で、対象日は「米国の前日」になる。
- 米国の祝日は日本と別。対象日（米国の営業日）の決め方が東証版と別に要る。
- 決算には「寄り前」と「引け後」がある。
  - 当日の値動きに出るのは、**当日の寄り前**と**前日の引け後**に出た決算。
  - **当日の引け後**に出た決算は、時間外の値動きでしか見えない。
  - 決算一覧表は、この両方を対象にする。

### 日経先物（2026-11-13 すみぽん了承）

- **大阪の夜間取引の終値を主にする。** 「日経平均の前日終値より○円高い／安い」と出し、今朝の寄り付きの目安にする。
- 取れなかった日は CME（シカゴ）で代用し、どちらの値かを画面に明記する。
- 理由：個人投資家がふだん見ているのは大阪の夜間。CME は大阪とほぼ同じ値になるので、両方出しても情報は増えない。

### 個別株ニュース（2026-11-13 すみぽんの修正を反映）

- 1銘柄1ページはやめて、**一覧の形で1ページに5銘柄**にする（決算一覧と同じ考え方）。
- 1銘柄に「銘柄名・変動率（％）・材料の見出し・説明」を載せる。
  - 横（1920×1080）：1銘柄2行。1行目は銘柄・変動率・見出し、2行目は説明（約40字・1行）。行に使える高さ約820px を5銘柄で分けて1銘柄約160px。
  - 縦（1080×1920）：1銘柄3行。1行目は銘柄・変動率、2行目は見出し、3行目以降は説明（2行まで）。1銘柄約300px。
- 銘柄は、ツールが渡した「変動率の高い銘柄」「決算銘柄」の中から、AI が材料を確認できたものを選ぶ。5銘柄に満たない日は、ある分だけ出す。
- 決算一覧に載っている銘柄と重なってもよいが、説明は決算の数字ではなく「なぜ動いたか」を書かせる。
- 読み上げは1銘柄1〜2文（約8秒）。5銘柄で約40秒。

### 決算一覧表（2026-11-13 すみぽんの修正を反映）

**数字の列はやめて、天気で示す。** 視聴者が数字を読み比べなくても、一目で良し悪しがわかるようにするため。数字はコメント欄に書く。

| 列 | 中身 | 出し方 |
|---|---|---|
| 銘柄 | 銘柄名（ティッカー）と、決算の時間（寄り前・引け後） | 文字 |
| 値動き | 当日の値動き（％）と時間外の値動き（％） | **数字のまま**（上げは赤・下げは緑など、東証版と同じ色分け） |
| 売上 | 売上をコンセンサスと比べた結果 | 天気 |
| 利益 | EPS をコンセンサスと比べた結果 | 天気 |
| ガイダンス | 会社見通し | 天気（判定できないときは「－」） |
| コメント | 何が良かった／悪かったか。主な数字もここに書く | 1行程度の短い文 |

**天気の決め方**

- 売上・利益（EPS）は**別々に**天気を出す（2026-11-13 すみぽん）
  - 晴れ＝予想を上回った
  - 曇り＝ほぼ予想どおり
  - 雨＝予想を下回った
  - 判定はツールが Finnhub の予想・実績から計算する（AI には決めさせない）。
  - **基準は「株価に影響するくらいの差か」で決める（2026-11-13 すみぽん）。** 下の「天気の基準（調べている途中）」を参照。
- ガイダンス
  - 晴れ＝上方修正、または見通しが予想を上回った
  - 曇り＝据え置き、またはほぼ予想どおり
  - 雨＝下方修正、または見通しが予想を下回った
  - 「－」＝ガイダンスを出していない、または確認できなかった
  - Finnhub（無料）にはガイダンスのデータが無い見込み。ガイダンスは **AI がニュースから判定**し、出典を付けさせる。確認できなければ「－」にする。
- 「売上は晴れ、利益は雨」「売上・利益は晴れ、ガイダンスは雨」といったズレがいちばんの見どころになる（米国決算はガイダンスが弱いと売られやすい）。台本でもここに触れさせる。
- 天気の列の見出し（売上・利益・ガイダンス）は表の上に1回だけ出す。

**コメント欄**

- 1銘柄1行程度（横は約25字、縦は2行まで）。AI が書く。
- 何が良かった／悪かったかを書く。主な数字（EPS・売上の実績と予想、成長率など）はここに入れる。
- ガイダンスの上方・下方修正があった場合は、**必ず**触れる。
- 例：「データセンター売上が予想超え。通期見通しを上方修正」「EPS 1.25ドル（予想1.10）も、来期見通しが予想を下回る」

**件数と文字の大きさ**

- **1ページ8銘柄、最大2ページ（16銘柄）**。5銘柄から増やす。
- 文字は東証版のランキングより一回り小さくする。見える見込み：
  - 横（1920×1080）：1銘柄1行。見出しを除いて行に使える高さは約820px。8行なら1行約100px で、文字は 34〜40px にできる。列は「銘柄・値動き2つ・天気3つ」を短くし、残りの幅（約850px、約25字）をコメントに回す。
  - 縦（1080×1920）：1銘柄2行にする（2026-11-13 すみぽん）。
    - 1行目：銘柄　変動率（当日・時間外）　天気（売上・利益・ガイダンス）
    - 2行目：コメント（幅いっぱい使える）行に使える高さは約1500px で、8銘柄なら1銘柄約185px、文字は 34〜40px。スマホの画面（幅約390pt）で見ると約13〜15pt 相当で、読める大きさ。
  - 実際の見え方は、部品を作るときにスマホで確かめて決める（読みにくければ1ページ6銘柄にする）。
- 読み上げは全銘柄ではなく、注目の2〜3銘柄だけ（東証版のランキングと同じ扱い）。

### 確かめてわかった注意点

- **時間外の取引は日本時間の朝10時（米国の20時）まで続く。** 朝に作ると、時間外の値動きは「作った時点の値」になる。画面と台本に「日本時間○時時点」と書く。
- 引け後の決算は米国の16時過ぎ（日本時間 6 時過ぎ）に出る。Finnhub に実績が入るまでの時間は、まだ確かめていない（今回は約14時間後に確認）。**次の朝に、何時に入るかを確かめる。**

### Finnhub に実績が入っていないときは、AI が一次情報から補う（2026-11-13 すみぽん）

- 予想（コンセンサス）は発表前から Finnhub に入っているので、そのまま使う。**補うのは実績（EPS・売上）だけ。**
- AI には、会社の決算発表（プレスリリース・SEC への提出書類 8-K・IR ページ）から実績を拾わせる。ニュース記事や他人のまとめは使わない。
- 出典の URL を必ず付けさせる。拾えなかった銘柄は空欄のままにし、天気は「－」にする（推測で埋めない）。
- EPS は**調整後（Non-GAAP）**を拾わせる。コンセンサスは調整後で比べるのがふつうなので、GAAP の EPS と比べると判定を間違える（Nasdaq のシスコの値がおそらくこの間違い）。会社が調整後を出していなければ GAAP を使い、そのことを書かせる。
- 単位を揃える（売上は「百万ドル」「十億ドル」の混在に注意）。ツールが予想と桁が大きく違わないか確かめ、違えば使わない。
- 天気の判定は、補った数字でもツールが計算する（AI に天気を決めさせない方針は変えない）。
- どの数字を AI が補ったかは保存しておき、②ファクトCK の画面で目印を付けて見せる（動画には出さない）。
- 作る前に Finnhub をもう一度取り直し、そのときに実績が入っていれば Finnhub の値を優先する。
- 日経先物の値も、取った時点の値になる。夜間の取引は朝 6 時に終わるので、6 時より後に取れば夜間の終値になる。
- 天気の判定を実データで試すと（±1％で曇り）：
  - シスコ：EPS 1.40（予想 1.35、+3.5％）＝晴れ、売上 185.2億ドル（予想 185.0億、+0.1％）＝曇り
  - アプライド・マテリアルズ：EPS +0.6％＝曇り、売上 −0.9％＝曇り
  - Nu：EPS −4.8％＝雨、売上 −0.6％＝曇り
  - EPS は予想との差が数％でも大きいので、±1％ で曇りの幅として妥当そう。売上は差が小さく出やすいので、±0.5％ くらいでもよいかもしれない（実データを見て決める）。

- Claude のクラウドで作業するときの環境「stock-slide-generator」を作った（個人用）。許可しているのは上の取得先だけ（Yahoo・株探・Finnhub・Nasdaq・JPX・日経）。

## 天気の基準（調べている途中）

### 世間の基準（2026-11-13 に調べた）

- 業界で決まった幅は無い。
- 米国（FactSet などの集計）は「予想より上／同じ／下」の3つで、1セントでも上回れば beat 扱い。S&P500 の約8割が毎回 EPS の予想を上回る（5年平均で約78％）。会社が低めの見通しを出して少し上回るのが当たり前なので、市場は「上回ったか」より「どれだけ上回ったか」を見る。
- 日本は統一の基準が無い。マネックス証券のレポートでは、コンセンサスを5％以上上回ったものを「ポジティブサプライズ」として数えていた。
- そのまま「上回れば晴れ」にすると、ほとんど晴れになって天気の意味が無くなる。

### たたき台（すみぽんの確認待ち）

上下で幅を変える（少し上回った程度は曇り、下回ったら厳しめに雨）。

| | 晴れ | 曇り | 雨 |
|---|---|---|---|
| EPS | +3％以上 | −1％〜+3％ | −1％より下 |
| 売上 | +1％以上 | −0.5％〜+1％ | −0.5％より下 |

- 予想が赤字やゼロに近い（例：|予想| < 0.10ドル）ときは、％ではなく上回ったか下回ったかの向きだけで決める。
- 幅は ⚙設定で変えられるようにする。

### 実データで「どれくらいの差で株価が動いたか」を調べる（途中）

すみぽんの「株価に影響するくらい」を数字にするため、直近1か月（2026-10-12〜11-12）の決算で、予想との差と翌日の株価の動き（S&P500 との差）を突き合わせる。

- スクリプト：`docs/design/2026-11-13_米国版_決算の反応の分析/`
  - `collect.py`：Finnhub の決算カレンダー（売上予想10億ドル以上・寄り前／引け後が分かるもの、約770件）と、Yahoo の日足を取る。出力は JSON（引数で場所を指定）。
  - `prices.py`：Yahoo の日足を1件ずつ間隔をあけて取り直す（同時に取ると Yahoo に止められた）。

## 取得の API（2026-11-14）

`functions/api/us-sources.js`。`?part=markets|earnings|movers` で分けて呼ぶ（Cloudflare の1回の呼び出しで外へ取りに行ける回数に上限があるため。無料は50回）。part を付けなければ3つとも返す。回数の数え方は東証版の取得と同じ「データ取得」。

- **対象日**：S&P500 の日足のうち、取引が終わった最後の日（取引中なら前の日）。米国の祝日は日足に出ないので自然に飛ばす。`date=YYYY-MM-DD` で過去の日も指定できる。
- **markets**：上の11本を Yahoo の日足から出す（対象日の終値と前日比。米10年債は bp でも出す）。3指数にはチャート用の日足（`months`、初期値3か月）も付ける。Yahoo が取れないものは日経の API の値（取った時点の値）で埋める。
  - 日経先物：日経の API の `JNICN`（大阪）を主に、取れなければ Yahoo の `NIY=F`（CME）。日経平均の前日終値（`NK225`）との差を `vsNk225` に出す。
  - 日経の API は `indicatorValue/?indexes=NK225,DJI&commodities_futures=JNICN` のように、種類ごとに indicator_code を並べる（種類を付けないと空が返る）。返りのコードは quickapi のコード（`N101/T` など）なので、対応表 `NK_QUOTE` で戻す。
- **earnings**：Nasdaq の決算カレンダー（前日・当日。時価総額）＋ Finnhub（前日〜当日。予想・実績・寄り前／引け後）。
  - 対象：前日の引け後・当日の寄り前（当日の値動き＝`session: reacted`）と、当日の引け後（時間外＝`afterhours`）。
  - 時価総額が `mcap`（十億ドル。初期値10）以上か、`must` の銘柄。当日の値動きは Yahoo の spark（20銘柄ずつまとめた日足＝公式の終値）、時間外は当日の引け後の銘柄だけ5分足から出す。
  - 載せる銘柄（`picked`）：`must` → 値動き（引け後の銘柄は時間外）の大きい順に `max`（初期値16）件。
  - 天気は `weatherOf` で計算する（たたき台の幅。`eu/ed/su/sd` で変えられる）。ガイダンスは `null`（AI が判定する）。実績が無い載せる銘柄は `missingActual` に並べる（AI が一次情報から補う対象）。
  - **Nasdaq には寄り前／引け後が入っていない日がある**（2026-11-12 は全部 `time-not-supplied`）。Finnhub が無いと時間がわからず、全部「当日の値動き」扱いになる（`hourUnknown: true`）。
- **movers**：Yahoo のスクリーナー（値上がり・値下がり・売買の多い。各50件から、時価総額が `mcap`＝初期値20億ドル以上の25件）。スクリーナーはいちばん新しい取引日の値なので、過去の日を指定しても今の値になる。
- 5分足の終値は公式の終値と少しずれる（シスコ 2026-11-12：5分足 101.90、公式 102.01）。当日の値動きは日足（spark）で出し、5分足は時間外の値にだけ使う。
