# 米国市場の振り返り（全自動版）の方針（2026-11-13）

日本（東証）の全自動版に加えて、米国市場の振り返り動画を作る。**まだ相談の段階で、実装はしていない。** データが実際に取れるかも未確認（下の「作る前に確かめること」）。

## すみぽんの指示（2026-11-13）

- 全自動版で作る。作りは東証の全自動版と同じ。
- 個別株ランキング・業種別の場面は**なし**。
- 指数は米国のほかに、日経先物・ドル円・ビットコイン・金・債券金利も出す（場面は分けてよい）。SOX・ラッセル2000・VIX・原油も入れる。
- ニュースは市場全体のほかに、**個別株のページ**も作る。
- **決算一覧表**を作る（当日に決算を発表して大きく動いた株、注目度の高い株。値動き・コンセンサス・実績）。引け後の発表は時間外の値動きが大事なので、時間外も入れる。
- ニュースと個別株の情報は **AI で収集**する。
- ただし、**指数・変動率の高い銘柄（候補）・決算銘柄の一覧はツールが取得して、プロンプトで AI に渡す**（数字を AI に調べさせない）。
- 決算の予想・実績は、使えるなら Finnhub を使う。
- 成果物は横動画・縦動画・X 投稿文。週間まとめはまだ決めないが、あとからできるようにしておく。

## 前提：時間の扱いが東証版と違う

- 米国市場が閉まるのは日本時間の朝 6:00（冬時間。夏時間は 5:00）。作るのは日本の朝で、対象日は「米国の前日」になる。
- 米国の祝日は日本と別。対象日（米国の営業日）の決め方が東証版と別に要る。
- 決算には「寄り前」と「引け後」がある。
  - 当日の値動きに出るのは、**当日の寄り前**と**前日の引け後**に出た決算。
  - **当日の引け後**に出た決算は、時間外の値動きでしか見えない。
  - 決算一覧表は、この両方を対象にする。

## 場面の構成（案）

| # | 場面 | 中身 |
|---|---|---|
| 0 | サムネ・表紙 | 東証版と同じ |
| 1 | 米国3指数 | ダウ・S&P500・ナスダック＋チャート（東証版の指数の場面を流用） |
| 2 | 米国その他の指数 | SOX（半導体）・ラッセル2000・VIX |
| 3 | 日本への影響 | 日経先物・ドル円 |
| 4 | 金利・資産 | 米10年債利回り（＋2年債）・金・ビットコイン・原油 |
| 5 | 市場全体のニュース | 東証版と同じ形（3〜5本） |
| 6 | 個別株ニュース | 1銘柄1ページ、3銘柄（多い日でも4まで） |
| 7 | 決算一覧表 | 1ページ5行、最大2ページ（10銘柄） |
| 8 | まとめ | 東証版と同じ |

- 場面 3 と 4 は分けておく（週間まとめで場面ごとの画像にしやすい）。
- 決算が少ない日は決算一覧を1ページだけにし、無い日は場面ごと出さない。

### 日経先物（提案。すみぽんの確認待ち）

- **大阪の夜間取引の終値を主にする。** 「日経平均の前日終値より○円高い／安い」と出し、今朝の寄り付きの目安にする。
- 取れなかった日は CME（シカゴ）で代用し、どちらの値かを画面に明記する。
- 理由：個人投資家がふだん見ているのは大阪の夜間。CME は大阪とほぼ同じ値になるので、両方出しても情報は増えない。

### 個別株ニュースのページ（提案。すみぽんの確認待ち）

- 1ページに「銘柄名・値動き（％）・材料の見出し・説明2〜3行」。縦でも横でも同じ配置で読める量にする。
- 1銘柄の読み上げは約10秒。3銘柄で30秒。

### 決算一覧表（提案。すみぽんの確認待ち）

- 列：銘柄／決算の時間（寄り前・引け後）／値動き（％）／EPS 予想→実績／売上 予想→実績／時間外の値動き。
- 横は1行に全部並べる。縦は列が入りきらないので、1銘柄を2段にする（上段：銘柄と値動き・時間外、下段：EPS と売上）。
- 予想を上回ったか下回ったかは色で示す。
- 読み上げは全銘柄ではなく、注目の2〜3銘柄だけ（東証版のランキングと同じ扱い）。

## データの分担

**ツールが取得するもの（数字。AI には調べさせず、プロンプトに入れて渡す）**

| データ | 使い道 | 取得先の候補 |
|---|---|---|
| 指数・先物・為替・金・ビットコイン・原油・金利の終値と前日比 | 場面 1〜4 にそのまま出す | Yahoo Finance の JSON。予備に株探US・stooq |
| 上のチャート用の日足 | 場面 1 のチャート | 同上 |
| 日経先物（大阪の夜間） | 場面 3 | 株探など（CME は Yahoo） |
| 変動率の高い銘柄の一覧（候補） | 個別株ニュースの銘柄を AI が選ぶ材料。**場面には出さない** | Yahoo のランキングなど |
| 決算銘柄の一覧（予想・実績・発表の時間・値動き・時間外） | 決算一覧表にそのまま出す。AI にも渡す | Finnhub（無料のキー）。値動きは Yahoo |

**AI が収集するもの（文章）**

- 市場全体のニュース（3〜5本）。
- 個別株の材料：ツールが渡した「変動率の高い銘柄」「決算銘柄」の中から、材料が確認できた銘柄を選んで書く。
- 台本・まとめ・サムネ案・X 投稿文（東証版と同じ流れ）。

**銘柄の選び方**

- 決算一覧に載せる銘柄：「時価総額が一定以上 × 値動きの大きさ」で自動に選ぶ。
- 加えて、設定に「必ず載せる銘柄」の登録欄を置く（初期値は Mag7 など）。値動きが小さい日でも注目の決算が漏れないようにするため。

## 画面・作り

- 作りは東証の全自動版と同じ（①取得・抽出 → ②ファクトCK → ③動画 → ④SNS）。
- 上のタブに「米国版」を足し、東証版とは別の状態で持つ（保存のキーを分ける）。
- 動画の部品（kessan-viz）に米国用の場面（資産の場面・個別株ニュース・決算一覧表）を足す。**直しは kessan-visualizer の src/ に入れる**（バンドルを直接書き換えない）。指数の場面は流用する。
- 週間まとめをあとから足せるよう、場面ごとのデータは東証版と同じ形でサーバーに保存する。

## 作る前に確かめること

取れないものがあると構成が変わるので、実装の前に確かめる。

1. Yahoo Finance の JSON が Cloudflare から取れるか（指数・先物・為替・金・ビットコイン・原油・金利・日足）。弾かれる場合の予備。
2. 大阪の夜間の日経先物の終値がどこから取れるか。
3. Finnhub の無料キーで、EPS と売上の予想・実績、発表の時間（寄り前・引け後）が取れるか。日本時間の朝の時点で実績が入っているか。
4. 時間外の値動きがどこから取れるか。
5. 変動率の高い銘柄の一覧（S&P500 など対象を絞ったもの）がどこから取れるか。

- 日経先物は「大阪の夜間が主、CME は代用」でよいか。
