# 東証ツールに Cloudflare Access でログインを掛ける

東証ツールの本番URLに、決算ツールと同じログインを掛ける手順です。上から順にそのまま進めれば終わります（5 分ほど）。

- なぜ要るか：Gemini を画面から直接呼ぶ形（3.8 Flash が 125 秒で切られる問題の対策）では、APIキーを画面に渡します。ログインが無いと、URL を知っている人なら誰でもキーを受け取れてしまうためです（今の `/api/analyze` も、ログインが無いので誰でも使える状態です）。
- 本番URL: `https://ssg-9506afd114d7.pages.dev/`
- Pages のプロジェクト名: `ssg-9506afd114d7`
- Zero Trust のチームは決算ツールで作った `naresla` をそのまま使います（新しく作らない）。

---

## 1. アプリケーションを追加する

1. 開く: https://one.dash.cloudflare.com/
   - チームを選ぶ画面が出たら `naresla` を選ぶ。
2. 左の「アクセス（Access）」→「アプリケーション（Applications）」を開く。
   - 決算ツール用の `kessan-tool` が並んでいるはずです。それとは別に、もう1つ作ります。
3. 「アプリケーションを追加（Add an application）」→「セルフホスト（Self-hosted）」を選ぶ。
4. 次のように入れる。
   - アプリケーション名:
     ```
     stock-slide-generator
     ```
   - セッション期間（Session Duration）: `1 month`（いちばん長いもの）
   - パブリックホスト名（Public hostname）→「ドメインを追加」で、本番のホスト名を入れる。
     ```
     ssg-9506afd114d7.pages.dev
     ```
     - ドメインのプルダウンに `pages.dev` が出ない場合は、入力欄に上のホスト名を丸ごと貼ってください。
   - 「次へ（Next）」
5. ポリシーを作る。
   - 決算ツールで作ったポリシー `me` を選べる場合は、それを選ぶだけでよいです。
   - 選べない場合は新しく作る：
     - ポリシー名: `me`
     - アクション: `許可（Allow）`
     - ルールの「含める（Include）」→ セレクター `メール（Emails）` → 値に決算ツールのログインと同じメールアドレスを入れる。
   - 「次へ」→ そのまま「保存（Save）」。
6. ログイン方法は決算ツールと同じものが使われます。そのままで完了です。

## 2. 確かめる

1. ブラウザで https://ssg-9506afd114d7.pages.dev/ を開く。
2. ログイン画面が出て、ログイン後にいつもの東証ツールが開けば完了です。

### 注意（前に困ったところ）

- Pages プロジェクトの設定にある「アクセスポリシーを有効化（Enable access policy）」は**押さない**でください。プレビュー用URL（`〜.pages.dev` の前に枝名がつくもの）専用で、本番には効きません。
- 似た名前の別プロジェクト（`stock-analysis-slide-〜.pages.dev` など）ではありません。`ssg-9506afd114d7` です。

## 終わったら

チャットで「東証ツールに Access を掛けた」と伝えてください。こちらで、APIキーを渡す口（`/api/gemini-key`）をログイン済みのときだけ動くようにして仕上げ、デプロイと確認をします。
