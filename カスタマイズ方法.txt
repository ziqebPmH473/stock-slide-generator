====================================================
  相場レポート スライド生成ツール カスタマイズ方法
====================================================

index.html をテキストエディタ（メモ帳、VSCode 等）で開いて編集してください。
変更箇所は <style> タグ内の CSS か、<script> タグ内の JavaScript です。
変更後はブラウザをリロードし、テキストを再貼り付けするとプレビューに反映されます。

----------------------------------------------------
【1】スライドのタイトル文字サイズ
----------------------------------------------------
対象CSS: .s-title の font-size

  .s-title {
    font-size: 68px;   ← ここを変更（大きく/小さく）
    ...
  }

※各スライド固有のタイトル:
  ニューススライド「本日のニュース」:
    .news-main-title { font-size: 52px; }   ← ここを変更

  表紙スライドのタイトル:
    .cover-title { font-size: 64px; }       ← ここを変更

  表紙スライドの本文:
    .cover-body  { font-size: 22px; }       ← ここを変更

----------------------------------------------------
【2】テーブルの文字サイズ
----------------------------------------------------
対象CSS: .tbl の font-size（テーブル全体に適用）

  .tbl { ...  font-size: 21px;  ... }   ← ここを変更

列ヘッダー行（銘柄名・コード・株価など）の文字サイズ:
  .tbl th { ... font-size: 21px; ... }   ← 別途指定可

----------------------------------------------------
【3】テーブルの列幅
----------------------------------------------------
各スライドの <thead> 内の <th style="width:XX%"> で調整します。
合計が 100% になるよう設定してください（table-layout:fixed が適用済み）。

■ 上昇率・下落率（同じ列幅を共有）
  検索キー: style="width:42%">銘柄名

  <th style="width:42%">銘柄名</th>
  <th style="width:12%">コード</th>
  <th style="width:18%">株価</th>
  <th style="width:28%">前日比</th>

■ 寄与度（プラス・マイナスで同じ変数を使用）
  検索キー: koyoThead=

  const koyoThead = `<thead><tr>
    <th style="width:50%">銘柄名</th>
    <th style="width:18%">コード</th>
    <th style="width:32%">寄与度</th>
  </tr></thead>`;

■ 売買代金
  検索キー: style="width:34%">銘柄名

  <th style="width:34%">銘柄名</th>
  <th style="width:10%">コード</th>
  <th style="width:18%">株価</th>
  <th style="width:22%">前日比</th>
  <th style="width:16%">売買代金</th>

■ 業種（上位・下位で同じ変数を使用）
  検索キー: gyoThead=

  const gyoThead = `<thead><tr>
    <th style="width:56%">業種</th>
    <th style="width:22%">変動率</th>
    <th style="width:22%">PER</th>
  </tr></thead>`;

----------------------------------------------------
【4】指数スライドの文字サイズ
----------------------------------------------------
大きな数値（58,753.39 など）:
  .idx-val { font-size: 100px; }   ← ここを変更

指数名（日経平均・TOPIX など）:
  .idx-name { font-size: 26px; }   ← ここを変更

前日比（+170.27（+0.29%）など）:
  .idx-chg { font-size: 24px; }    ← ここを変更

----------------------------------------------------
【5】プラス・マイナスの色
----------------------------------------------------
青（プラス）:
  .pos { color: #1d4ed8; }   ← 16進数カラーコードを変更

赤（マイナス）:
  .neg { color: #dc2626; }   ← 16進数カラーコードを変更

よく使う色コード例:
  青: #1d4ed8（濃紺）/ #2563eb（青）/ #0284c7（水色）
  赤: #dc2626（赤）/ #e11d48（ピンク赤）

----------------------------------------------------
【6】テーブルの列ヘッダー文字を変更
----------------------------------------------------
JavaScript の slideRank, slideKoyo, slideBaibai, slideGyoshu 関数内の
<thead> 部分を編集します（【3】の列幅と同じ箇所）。

例）上昇率・下落率スライドの列名:
  <th style="width:42%">銘柄名</th>  ← 「銘柄名」の文字を変更

----------------------------------------------------
【7】スライドの各タイトル文字列（固定テキスト）
----------------------------------------------------
各関数内の s-title 部分を変更します。

slideCover()               → 入力テキスト [表紙] セクションの1行目
slideIndices()             → 「国内主要株価指数」
slideRank('上昇率', ...)  → 「株価上昇率ランキング」
slideRank('下落率', ...)  → 「株価下落率ランキング」
slideKoyo()               → 「日経平均寄与度ランキング」
slideBaibai()             → 「売買代金ランキング」
slideGyoshu()             → 「業種別変動率ランキング」

寄与度スライドのサブタイトル「プラス寄与度トップ5」「マイナス寄与度トップ5」:
  slideKoyo() 関数内の文字列を直接編集

業種スライドのサブタイトル「上位5業種」「下位5業種」:
  slideGyoshu() 関数内の文字列を直接編集

----------------------------------------------------
【8】分割スライドのサブ見出しサイズ
----------------------------------------------------
「プラス寄与度トップ5」「上位5業種」などのサイズ:
  .s-sub { font-size: 26px; }   ← ここを変更

----------------------------------------------------
【9】ニュース項目のサイズ
----------------------------------------------------
ニュース項目タイトル（太字の見出し）:
  .news-item-title { font-size: 24px; }   ← ここを変更

ニュース項目本文:
  .news-item-body { font-size: 18px; }    ← ここを変更

----------------------------------------------------
【10】スライドのサイズ（1280×720 を変更したい場合）
----------------------------------------------------
CSSの .slide のサイズ:
  .slide { width: 1280px; height: 720px; ... }

JavaScriptの定数:
  const SLIDE_W = 1280, SLIDE_H = 720;

この2か所を同じ値に変更してください。
（プレビューの縮小率も自動調整されます）

----------------------------------------------------
【11】銘柄名の自動縮小の閾値変更
----------------------------------------------------
列幅が広いスライド（上昇率・下落率・売買代金）と
列幅が狭いスライド（寄与度・業種：2分割のため）で
閾値が分かれています。JavaScript の NAME_SHRINK 定数を変更:

  const NAME_SHRINK = {
    wide:   [22, 30],  ← 上昇率・下落率・売買代金（22超→17px、30超→14px）
    narrow: [14, 20],  ← 寄与度・業種（14超→17px、20超→14px）
  };

※全角1文字=2、半角1文字=1 として計算した合計値が閾値と比較されます。
例）「ファーストリテイリング」= 11文字 × 2 = 22 → wide では縮小なし、
                                                    narrow では14px相当に縮小

----------------------------------------------------
【12】タイトルの縦位置・行間の調整
----------------------------------------------------
■ タイトルの上余白（スライドごとに個別設定）
  JavaScript の TITLE_PAD 定数:

  const TITLE_PAD = {
    表紙:     52,   ← 表紙スライド
    指数:     70,   ← 国内主要株価指数
    上昇率:   60,   ← 株価上昇率ランキング
    下落率:   60,   ← 株価下落率ランキング
    寄与度:   60,   ← 日経平均寄与度ランキング
    売買代金: 60,   ← 売買代金ランキング
    業種:     90,   ← 業種別変動率ランキング
    ニュース: 52,   ← 本日のニュース（画像あり・なし共通）
  };

  値を大きくする → タイトルが下にずれる（上余白が増える）
  値を小さくする → タイトルが上にずれる

■ タイトルと内容の間隔（スライドごとに個別設定）
  JavaScript の TITLE_GAP 定数:

  const TITLE_GAP = {
    表紙:     36,
    指数:     16,   ← ※idx-cellのpadding-top(28px)も視覚的余白に加算される
    上昇率:   60,
    下落率:   60,
    寄与度:   15,
    売買代金: 60,
    業種:     15,
    ニュース: 36,   ← 画像あり・なし共通
  };

  値を大きくする → タイトルと表（または記事）の間隔が広がる
  値を小さくする → 間隔が縮まる

  ※プレビューは縮小表示のため小さな変化は見えにくい。PNG出力で確認推奨。

■ 指数間の縦の行間（日経平均〜東証スタンダードなどの間隔）
  CSS の .idx-grid:

  .idx-grid { row-gap: 0; ... }   ← 0px が最小。大きくすると間隔が広がる

----------------------------------------------------
【13】タイトルの横位置調整
----------------------------------------------------
デフォルトは左寄せ。変更する場合:
  .s-title { text-align: center; }   ← 中央揃え
  .s-title { text-align: right;  }   ← 右揃え

----------------------------------------------------
【参考：入力フォーマット】
----------------------------------------------------
テキストの各セクションは [セクション名] で区切ります:
  [表紙]       → 表紙スライド（1行目=タイトル、2行目以降=本文）
  [指数]       → 国内主要株価指数スライド
  [上昇率]     → 株価上昇率ランキング
  [下落率]     → 株価下落率ランキング
  [寄与度]     → 日経平均寄与度ランキング（--- で上下を区切る）
  [売買代金]   → 売買代金ランキング
  [業種]       → 業種別変動率ランキング（--- で上下を区切る）
  [ニュース]   → 本日のニュース（最大5件）

各行のデータは | （パイプ）で区切ります。

【17】縦型サムネ（SNS用）の調整
────────────────────────────────────────
⑤出力の「縦型サムネ（SNS用）」で作る画像です。
・サイズ  … 9:16（1080×1920, 初期値）／4:5（1080×1350）を選択
・構成    … 2段構成／3段構成を選択（3段構成のときだけ3段目の枠が出ます）
・文言    … 1段目〜3段目の枠に分けて入力。枠内で改行すると、その位置でそのまま改行されます。
             色指定は横サムネと同じ（*橙* / #水# / %黄%）。
・⑤出力を開くと、④スライドの「サムネ文言」を「：」で分割して各段の枠に自動で流し込みます
  （枠を手で直したあとは、文言が変わるまで上書きしません。「📥 サムネ文言から取込」で手動取込も可能）。

見た目は index.html の const VTHUMB で調整します。
  headLabel  … 上部バーの見出し（初期値「マーケット速報」）
  headH      … 上部バーの高さ（px）／ headFs は文字サイズ
               ※スマホ表示は幅390pt換算で約0.36倍になるため、46px≒17pt。
                 これ以上小さくすると本文より読みにくくなります
  headAccent … 見出し左のアクセント色
  footLabel  … 下部バーの右に出す文言（初期値「タップで動画を再生」）
  footH/footFs/footColor … 下部バーの高さ・文字サイズ・文字色（背景は黒 footBg）
  ratios3 / ratios2 … 各段の高さ比率（3段構成／2段構成）
  maxChars   … 文字サイズの上限（全角この文字数ぶんの幅。初期値5＝全角5文字で幅いっぱい）
  ※上部バーは画像の上端、下部バーは下端に固定し、その間は帯（本文）で全面を埋めます。
    黒はバーの範囲と黒帯だけで、帯の上下に黒の余白は作りません。
  ※文字サイズは「枠ごと」ではなく「行ごと」に決まります。各行は帯の幅いっぱいまで
    大きくなり、上限は全角 maxChars 文字ぶんの幅。行を積んで帯に収まらないときだけ
    全行を同じ比率で縮めます。
  ※2段構成では2つの枠の文字を画像全体の中央「寄り」に置きます（1段目は下寄せ・2段目は上寄せ）。
    境目にはくっつけず余白を残し、その量は gap2（帯の高さに対する比率・初期値0.14）で調整します。
    3段構成は各帯の中央です。
