====================================================
  相場レポート スライド生成ツール カスタマイズ方法
====================================================

index.html をテキストエディタ（メモ帳、VSCode 等）で開いて編集してください。
変更箇所は <style> タグ内の CSS か、<script> タグ内の JavaScript です。

----------------------------------------------------
【1】スライドのタイトル文字サイズ
----------------------------------------------------
対象CSS: .s-title の font-size

  .s-title {
    font-size: 68px;   ← ここを変更（大きく/小さく）
    ...
  }

※ニューススライドのタイトル「本日のニュース」は別箇所:
  .news-main-title {
    font-size: 52px;   ← ここを変更
    ...
  }

----------------------------------------------------
【2】テーブルの文字サイズ
----------------------------------------------------
対象CSS: .tbl の font-size（テーブル全体に適用）

  .tbl { ...  font-size: 21px;  ... }   ← ここを変更

列ヘッダー（銘柄名・コード・株価など）の文字サイズは:
  .tbl th { ... font-size: はなし（tbl から継承）。個別に変えたい場合は追加 }

----------------------------------------------------
【3】指数スライドの文字サイズ
----------------------------------------------------
大きな数値（58,753.39 など）:
  .idx-val { font-size: 100px; }   ← ここを変更

指数名（日経平均・TOPIX など）:
  .idx-name { font-size: 26px; }   ← ここを変更

前日比（+170.27（+0.29%）など）:
  .idx-chg { font-size: 24px; }    ← ここを変更

----------------------------------------------------
【4】プラス・マイナスの色
----------------------------------------------------
青（プラス）:
  .pos { color: #1d4ed8; }   ← 16進数カラーコードを変更

赤（マイナス）:
  .neg { color: #dc2626; }   ← 16進数カラーコードを変更

よく使う色コード例:
  青: #1d4ed8（濃紺）/ #2563eb（青）/ #0284c7（水色）
  赤: #dc2626（赤）/ #e11d48（ピンク赤）

----------------------------------------------------
【5】テーブルの列ヘッダー文字を変更
----------------------------------------------------
JavaScriptの slideRank, slideKoyo, slideBaibai, slideGyoshu 関数内の
<thead> 部分を編集します。

例）上昇率・下落率スライドの列名:
  <thead><tr><th>銘柄名</th><th>コード</th><th>株価</th><th>前日比</th></tr></thead>
                              ↑ここを変更

例）売買代金スライドの列名:
  <thead><tr><th>銘柄名</th><th>コード</th><th>株価</th><th>前日比</th><th>売買代金</th></tr></thead>

----------------------------------------------------
【6】スライドの各タイトル文字列（固定テキスト）
----------------------------------------------------
各関数内の s-title 部分を変更します。

slideIndices()    → 「国内主要株価指数」
slideRank('上昇率', ...) → 「株価上昇率ランキング」
slideRank('下落率', ...) → 「株価下落率ランキング」
slideKoyo()       → 「日経平均寄与度ランキング」
slideBaibai()     → 「売買代金ランキング」
slideGyoshu()     → 「業種別変動率ランキング」

寄与度スライドのサブタイトル「プラス寄与度トップ5」「マイナス寄与度トップ5」も
slideKoyo() 関数内の文字列を直接編集してください。

業種スライドのサブタイトル「上位5業種」「下位5業種」も
slideGyoshu() 関数内の文字列を直接編集してください。

----------------------------------------------------
【7】分割スライドのサブ見出しサイズ
----------------------------------------------------
「プラス寄与度トップ5」「上位5業種」などのサイズ:
  .s-sub { font-size: 26px; }   ← ここを変更

----------------------------------------------------
【8】ニュース項目のサイズ
----------------------------------------------------
ニュース項目タイトル（太字の見出し）:
  .news-item-title { font-size: 21px; }   ← ここを変更

ニュース項目本文:
  .news-item-body { font-size: 16px; }    ← ここを変更

----------------------------------------------------
【9】スライドのサイズ（1280×720 を変更したい場合）
----------------------------------------------------
CSSの .slide のサイズ:
  .slide { width: 1280px; height: 720px; ... }

JavaScriptの定数:
  const SLIDE_W = 1280, SLIDE_H = 720;

この2か所を同じ値に変更してください。
（プレビューの縮小率も自動調整されます）

----------------------------------------------------
【10】銘柄名の自動縮小の閾値変更
----------------------------------------------------
列幅が広いスライド（上昇率・下落率・売買代金）と
列幅が狭いスライド（寄与度・業種：2分割のため）で
閾値が分かれています。JavaScript の NAME_SHRINK 定数を変更:

  const NAME_SHRINK = {
    wide:   [22, 30],  ← 上昇率・下落率・売買代金（22超→17px、30超→14px）
    narrow: [14, 20],  ← 寄与度・業種（14超→17px、20超→14px）
  };

※全角1文字=2、半角1文字=1 として計算した合計値が閾値と比較されます。
例）「ファーストリテイリング」= 11文字 × 2 = 22 → wide では17px縮小なし、
                                                    narrow では14px相当に縮小

----------------------------------------------------
【11】タイトルの縦位置調整（スライドごとに個別設定）
----------------------------------------------------
JavaScript の先頭付近にある TITLE_PAD 定数で、スライドごとに
タイトルの上余白（padding-top px）を設定できます:

  const TITLE_PAD = {
    指数:     52,   ← 国内主要株価指数スライド
    上昇率:   52,   ← 株価上昇率ランキング
    下落率:   52,   ← 株価下落率ランキング
    寄与度:   52,   ← 日経平均寄与度ランキング
    売買代金: 52,   ← 売買代金ランキング
    業種:     52,   ← 業種別変動率ランキング
    ニュース: 52,   ← 本日のニュース（画像あり・なし共通）
  };

値を大きくすると → タイトルが下にずれる（上余白が増える）
値を小さくすると → タイトルが上にずれる

タイトルと表の間隔を変えたい場合は .s-title の margin-bottom を調整:
  .s-title { margin-bottom: 5px; }   ← 大きくすると間隔が広がる（現在5px）

■ ニュースのタイトル〜記事リスト間の余白は別の定数で制御:
  const NEWS_TITLE_GAP = 28;   ← 大きくすると間隔が広がる
  ※ニュース本数が変わってもタイトルの上位置は変わらず、下余白のみが変わります

■ 指数間の縦の行間（日経平均〜東証スタンダードの間隔）は CSS で調整:
  .idx-grid { row-gap: 0; ... }   ← 0px が最小。大きくすると間隔が広がる

----------------------------------------------------
【12】タイトルの横位置調整
----------------------------------------------------
デフォルトは左寄せ。変更する場合:
  .s-title { text-align: center; }   ← 中央揃え
  .s-title { text-align: right;  }   ← 右揃え

----------------------------------------------------
【参考：入力フォーマット】
----------------------------------------------------
テキストの各セクションは [セクション名] で区切ります:
  [指数]       → 国内主要株価指数スライド
  [上昇率]     → 株価上昇率ランキング
  [下落率]     → 株価下落率ランキング
  [寄与度]     → 日経平均寄与度ランキング（--- で上下を区切る）
  [売買代金]   → 売買代金ランキング
  [業種]       → 業種別変動率ランキング（--- で上下を区切る）
  [ニュース]   → 本日のニュース（最大5件）

各行のデータは | （パイプ）で区切ります。
